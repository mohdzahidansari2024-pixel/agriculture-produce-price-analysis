Project Information

Problem Statement

Agricultural prices change frequently due to supply, demand, seasonal conditions and market factors. This project provides a simple analytical system to study agricultural produce price movements.

Objectives

Analyse agricultural price data, calculate average, minimum and maximum prices, compare different commodities and visualize price trends.

Methodology

The dataset is stored in CSV format. JavaScript loads the dataset, processes the numerical values, calculates statistical measures and displays interactive visualizations.

Technologies Used

HTML, CSS, JavaScript, CSV Dataset, GitHub, GitHub Pages and Chart.js.

Scope

The system can be extended with more agricultural commodities, longer time periods, geographical market information and real-time market data.

Expected Outcome

A user-friendly analytical dashboard that helps understand agricultural price behaviour through statistics, comparisons, tables and graphs.

Conclusion

The project demonstrates how data analysis and visualization can transform agricultural price records into useful information for understanding market trends.

Dataset Note

The current dataset is academic/sample data prepared for project demonstration and analysis. It should not be treated as verified real-time mandi or market prices.
