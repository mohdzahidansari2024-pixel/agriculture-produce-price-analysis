📋 About the Project

This project analyzes the market prices of agricultural products such as tomato, onion and potato.

The project compares average prices and uses data visualization to understand agricultural price patterns.

💻 Technologies Used

Python   |   Pandas   |   Matplotlib   |   Google Colab

❓ Questions & Answers

Q1. What is the aim of this project?

Answer: The aim is to analyze and compare the market prices of agricultural products such as tomato, onion and potato.

Q2. Which technologies are used?

Answer: Python, Pandas, Matplotlib and Google Colab are used in this project.

Q3. Which agricultural products are analyzed?

Answer: Tomato, onion and potato prices are analyzed.

Q4. What is data analysis?

Answer: Data analysis is the process of examining data to find useful information, patterns and trends.

Q5. What is the benefit of this project?

Answer: It helps understand agricultural price patterns and compare the average prices of different products.

Q6. Which Python libraries are used?

Answer: Pandas is used for data analysis and Matplotlib is used for data visualization.

Q7. What is the source of the data?
