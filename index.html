Project Information

Problem Statement

Agricultural prices change frequently due to supply, demand, seasonal conditions and market conditions. Farmers and consumers may find it difficult to understand these price changes from raw data. This project provides a simple system to analyze and visualize agricultural produce prices.

Objectives

  • Analyze agricultural produce prices.
  • Calculate average, minimum and maximum prices.
  • Visualize price trends using graphs.
  • Compare prices of different agricultural products.
  • Present the analysis through an interactive dashboard.

Methodology

The dataset is collected in CSV format and processed using JavaScript. The system reads the data, filters it according to the selected year, calculates statistical values and displays the results through charts, comparison cards and tables.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Chart.js
  • CSV Dataset
  • GitHub Pages

Scope

The system can be extended with more agricultural products, larger datasets, real-time market prices, geographical market information and advanced forecasting techniques.

Expected Outcome

The project provides an easy-to-understand dashboard that helps users identify price patterns, compare agricultural products and understand changes in market prices.

Dataset Note

The dataset used in this academic project is sample educational data created for analysis and demonstration. It should not be treated as verified real-time mandi or market prices.

Conclusion

The Agricultural Price Analysis System demonstrates how data analysis and visualization techniques can be used to understand agricultural price trends. The dashboard makes the data easier to interpret and provides useful statistical insights through an interactive interface.
