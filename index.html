Project Information

Academic project documentation.

Problem Statement

Agricultural commodity prices fluctuate over time. Without proper analysis, it becomes difficult to understand price movements and compare different agricultural products. This project provides a simple analytical system for studying these changes.

Objectives

  • Analyse agricultural product prices.
  • Calculate average, minimum and maximum prices.
  • Visualize price trends.
  • Compare prices across products and years.
  • Present the analysis through an interactive dashboard.

Methodology

The dataset is maintained in spreadsheet/CSV format. Python and data analysis concepts are used for preprocessing and statistical analysis. The final results are presented through an interactive web dashboard.

Technologies Used

  • Python
  • Pandas
  • Matplotlib
  • HTML
  • CSS
  • JavaScript
  • Chart.js
  • Google Sheets / CSV
  • GitHub Pages

Scope

The system can be extended with more agricultural products, additional years, real-time market data, geographical comparisons, forecasting models and advanced machine learning techniques.

Expected Outcome

The project provides an easy-to-understand visual analysis of agricultural price patterns and helps users compare commodities using statistical values and interactive graphs.

Dataset Note

The dataset used for this academic demonstration contains sample price values for September 2025 and September 2026. Values are presented in Indian Rupees per kilogram (₹/kg) and should not be interpreted as verified real-time mandi prices.

Conclusion

Agricultural price analysis demonstrates how data science can convert raw price records into meaningful insights. The dashboard makes it easier to identify price variations, compare commodities and understand yearly trends.
