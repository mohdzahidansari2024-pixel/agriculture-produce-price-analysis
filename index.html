📋 About the Project

This project analyzes and compares the prices of three agricultural products: tomato, onion and potato.

The website uses data analysis and visualization to identify price patterns, compare average prices and understand minimum and maximum price variations.

💻 Technologies Used

Python | Pandas | Matplotlib | Google Colab | HTML | CSS | JavaScript | Chart.js

🎯 Project Objective

The objective is to present agricultural price information in a simple and interactive form so that users can easily compare different agricultural products.
